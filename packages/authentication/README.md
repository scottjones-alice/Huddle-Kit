# @alice/authentication

Sign-in, sessions and identity: **who is this?** It answers who is calling and which club (organization) they are acting in. It does not decide what they may do; that is [`@alice/authorization`](../authorization).

## Usage

```ts
import { name } from "@alice/authentication";
```

## Scripts

- `pnpm check-types` — type-check
- `pnpm test` — run tests with Vitest
