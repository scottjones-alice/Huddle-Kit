# @alice/database

Postgres database client and schema, built on [Drizzle ORM](https://orm.drizzle.team) (v1 relations API).

## Usage

```ts
import { createDatabase, users } from "@alice/database";
import { keys } from "@alice/database/keys";

const db = createDatabase({
  logger: keys().DATABASE_LOGGER,
  onPoolError: (error) => console.error(error),
  url: keys().DATABASE_URL,
});

const user = await db.query.users.findFirst({
  where: { email: "alex@example.com" },
  with: { members: true },
});
```

`createDatabase` never logs on its own. Pass `onPoolError` to decide what happens when an idle connection fails.

## Environment

Read from the single root `.env` (see `.env.example`):

- `DATABASE_URL` (required) — Postgres connection string.
- `DATABASE_LOGGER` (optional, default `false`) — log every SQL query.

## Structure

- `src/create-database.ts` — client factory.
- `src/keys.ts` — validated env variables.
- `src/schema/authentication.ts` — Better Auth tables and relations. Generated by the Better Auth CLI; regenerate it instead of editing by hand.
- `src/schema/people/` — `people`, `addresses`, `person_relationships`, `player_profiles`, `person_identifiers` (FA FAN), `qualifications`, `allergies`, `medical_records`.
- `src/schema/club/` — `club_settings`, `opponents`, `venues`, `pitches`. One organization is one club.
- `src/schema/files/` — `files`, `file_views`.
- `src/schema/football/` — `seasons`, `teams`, `team_memberships`, `registrations`, `events`, `event_series` (repeating events), `match_details`, `match_squad`, `event_availability`, `event_attendance`.
- `src/schema/finance/` — `fees`, `fee_charges`, `payments`. Money is whole minor units plus an ISO currency code.
- `src/schema/communications/` — `announcements`, `notifications`. There is deliberately no private messaging (safeguarding).
- `src/schema/governance/` — `audit_events` (append-only), `consents` and versioned `consent_documents` (wording is immutable), `role_assignments` and `role_assignment_teams`.
- `src/schema/welfare/`, `src/schema/safeguarding/` — incident reports; safeguarding checks (including DBS level), concerns and append-only notes.
- `src/audit.ts` — `recordAuditEvent`: validated write to the audit log. Call it on every read or change of sensitive data.
- `src/field-encryption.ts` — AES-256-GCM `createFieldEncryptor` for safeguarding text. The context binds a value to its row and column; key ids support rotation. The app must call it: the database stores whatever it is given.
- `src/series.ts`, `src/series-generation.ts` — `occurrencesBetween` (pure, time-zone aware) and `generateSeriesEvents` (creates the `events` rows up to a date; safe to re-run).
- `src/schema/relations.ts` — merges relation parts for `drizzle()`.
- `src/schema/index.ts` — the schema entry point drizzle-kit reads.
- `migrations/` — SQL migrations created by drizzle-kit.

## Scripts

- `pnpm db:generate` — create a migration from schema changes
- `pnpm db:migrate` — apply pending migrations
- `pnpm db:push` — push the schema straight to the database (local development only)
- `pnpm db:studio` — open Drizzle Studio
- `pnpm check-types` — type-check
- `pnpm test` — unit tests (no database needed)
- `pnpm test:integration` — runs the migrations and queries against a real Postgres. Needs `TEST_DATABASE_URL` pointing at an empty `huddlekit_test` database on your local Postgres. It never reads `DATABASE_URL`.

## Same-organization rules

Tables reference each other with composite foreign keys `(organization_id, x_id)`, so a row can never point at another club's data. Links that must be cleared when the target is deleted (`ON DELETE SET NULL`) cannot be composite in Drizzle, so they are single-column and the app must check the target is in the same organization: team training venue, club and opponent home venues, event and series venues, consent and check files, qualification files, consent `grantedByPersonId`, and the incident report's team, venue and first aider. Match details and squad rows only make sense for events with `kind = 'match'`; the app enforces that.
